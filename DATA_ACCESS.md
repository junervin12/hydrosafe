# Data Access

## Source dataset

The primary dataset used in this project is:

**Electrochemical Heavy Metal Sensor Data**

Source: Kaggle dataset by `colabsss`.

The dataset contains electrochemical sensor-response measurements for heavy metal detection and is used for heavy metal identification, concentration regression, and regulatory contamination-status mapping.
